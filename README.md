# NeuroFive ML Track

Exploratory Data Analysis (EDA) on the Titanic dataset as part of the NeuroFive ML learning track.

## What's covered
- Data inspection using pandas (`.info()`, `.describe()`, `.head()`)
- Missing value analysis and handling (`fillna()`, `dropna()`)
- Outlier detection using boxplots
- Visualizations with matplotlib and seaborn: histogram, boxplot, bar chart, and correlation heatmap
- Written analysis on which features most affect survival
